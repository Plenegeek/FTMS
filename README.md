## How to run?
- Make sure that g++ is installed.
- (In the terminal) Go to the dir you want to put FTMS on.
- Run: "Git clone https://github.com/Plenegeek/FTMS.git"
- Then run "cd FTMS"
- In the FTMS dir. run **make**
- Then ./ftms
  You should see the FTMS run almost instantly
