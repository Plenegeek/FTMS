FTMS - Fast Terminal Monitoring System

Want to see your temps and usage without having your whole terminal taken up?

## How to run?
- Make sure that g++ is installed.
- In the FTMS dir. run **make**
- Then ./ftms
  You should see the FTMS run almost instantly
